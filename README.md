# Discord Clone

A full-stack Discord clone built with Next.js, React 19, Socket.io, Prisma, PostgreSQL, Clerk, and LiveKit.

## Getting Started

### 1. Run the Next.js Web Application
```bash
npm run dev
```

### 2. Run the Socket.io Server (in a separate terminal)
```bash
npm run socket
```
